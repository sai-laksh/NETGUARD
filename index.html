              Threat Detection & Heuristic Pattern Analysis
            

            
Rule-based detection algorithms identifying predefined suspicious campus network behaviors using sample telemetry.

          

        


        
        

          

            
1. Traffic Volume

            
Unusual Bandwidth Surge

            
Flags sustained transfers exceeding 300 Mbps or 10k pkts/min from individual endpoints.

          


          

            
2. Failed Connections

            
Repeated Auth Failures

            
> 5 failed SSH/RDP connection resets within 60s window indicating brute-force attempts.

          


          

            
3. Communication Patterns

            
Cross-VLAN Violations

            
Unauthorized traversal from Student subnet directly attempting access to Admin DB ports.

          


          

            
4. Device Activity

            
Unexpected Device Behavior

            
Endpoints transmitting off-hours (22:00-06:00) or using out-of-profile non-standard protocols.

          


          

            
5. Port Activity

            
Unusual Port Probing

            
Sequential TCP SYN packets across ≥10 discrete ports within 15s without handshake completion.

            Future Integration with Cisco Packet Tracer & Wireshark
          

          

            

              Architecture Separation: NETGUARD separates the presentation layer (HTML/CSS/JS) from the network data processing layer (Python & Flask).
            

            
    
              
  • Wireshark Integration: Wireshark packet captures can be saved as CSV or PCAP files and analyzed using pcap_analyzer.py. The analyzer computes protocol distributions and identifies suspicious anomalies like port scanning and brute-force resets.
    • 
              
  • Cisco Packet Tracer Integration: Network topology exports and router syslog/flow files are parsed by packet_tracer_parser.py to map device statuses directly to the interactive topology diagram.
    • 
              
  • Live Data Replacement: In production, replacing data/*.json with dynamic feeds from the Python parser transitions NETGUARD from simulation mode into a live operational sensor.
